# NVFP4 BIZ 2.x（TensorFold）

[English](README.md) · [リポジトリの索引](../README.ja.md) · [変更履歴](CHANGELOG.ja.md)

2.x系は1.x系と同じNVIDIAの固定GLM-5.3-Flash NVFP4 checkpointを、vLLMに代えてTensorFoldで配信します。2.0.0に向けて準備中で、まだリリースはありません。それまでリリースされているのは[1.x系](../v1/README.ja.md)です。

## 目次（2.0.0で埋める）

- セットアップ：エンジンの固定、コンテナimage、2台のTP=2と3台のTP=3の起動の台本
- 配信profile：FP8 latent KV、NCCLの2本のrail、文脈の窓
- 検証：decode検査、NLL採点セット、1.x系と同じ項目の受け入れ表
